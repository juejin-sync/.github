## 项目简介

掘金同步助手是一款开源的 Chrome Manifest V3 浏览器扩展。它读取用户主动选择的掘金文章或编辑器草稿，处理正文与图片，并同步到已登录内容平台的草稿箱。

- 支持 CSDN、微信公众号和博客园草稿同步
- 内容转换在浏览器本地完成，不托管账号密码
- 只保存到目标平台草稿箱，不自动公开发布
- 支持多平台独立执行、状态记录和安全重试
